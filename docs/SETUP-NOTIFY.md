# スマホへの1日のまとめ（Discord）

毎日1回（設定の時刻。最初は日本時間21時）、ダッシュボードが「今日あったこと・失敗・あなたの確認待ち・費用」をまとめて送ります。
送り先は Discord のおすすめです（無料で、スマホのアプリに通知が届きます）。URLはチャットに貼らないでください。

1. Discord で自分だけのサーバーを作る（左の「＋」→「オリジナルの作成」→「自分と友達のため」）
2. 通知を受けるチャンネル（例: #ai-lab）の歯車 → **連携サービス → ウェブフック → 新しいウェブフック** を作り、**ウェブフックURLをコピー**
3. `.env.local` に1行足して、サーバーを再起動する

```
NOTIFY_WEBHOOK_URL=（ここにウェブフックURL）
```

4. ダッシュボードの **設定 → スマホへの1日のまとめ** の「今すぐ試しに送る」で、届くか確かめる

スマホの Discord アプリで、そのチャンネルの通知を「すべてのメッセージ」にしておくと、毎日の通知が届きます。
Slack の Incoming Webhook の URL を入れても届きます。
