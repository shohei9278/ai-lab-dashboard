- 日付: 2026-11-26
- 関わるもの: PR #191（仕組みの詰まり）・#200、本番の「AIの成績」と「提案箱」

## 起きたこと
- PR #191 で、工程ごとに止まっていた時間を記録から数える仕組みを入れた（AIは呼ばない）
- 11/26 昼の本番の数字（直近7日の合計 / 前の7日）
  - 提案箱の依頼待ち: 84.1日 / 56.3日（いま11件待ち・1件あたり平均2.7日）
  - 運営者へのお願い: 30.7日 / 40.4日（5件待ち・平均4.9日）

## 意外だった所・ぶつかった所
- 直すのは速い（頼んでからマージまで平均2時間）のに、頼むまでに平均2.7日かかっていた。詰まりは、AIの作業ではなく「頼む決まり」の側にあった

- 人の判断待ちは、前の7日より半分に減っていた

## 人がしたこと・言ったこと
- 運営者が、これを「詰める」と決め、Claude Code が勧めた「上限を広げて見回りを短くする（一度に1件は変えない）」で進めると決めた
- 運営者へのお願い5件は、運営者が返事をした（11/26）
