# 3回直しても残った指摘で、GPT と Gemini の判断が割れた

- 日付: 2026-11-25
- 関わるもの: PR #186（提案箱 #90「ツールの注意書きを紹介ページに渡す」）、自動マージの協議

## 起きたこと
- 提案箱のルーティンが作った PR #186 を、自動マージの見回りが GPT と Gemini にレビューさせた
- 指摘を受けてルーティンが3回直した（「確認してください」などの操作の案内まで注意書きとみなす → 別の文の言葉を組み合わせてしまう → 「保証します」のような打ち消していない言い方まで拾う）
