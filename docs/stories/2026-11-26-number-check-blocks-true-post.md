# AIが書いた「正直な実験の記録」の投稿を、AIの数字の確かめが止めた

- 日付: 2026-11-26
- 関わるもの: 本番の「毎日の計画」の 10:30 の予定、PR #197

## 起きたこと
- 朝会が、Threads に「実験の記録」の普通の投稿を予定に入れた。話題は「直近14日、Threads の遊ぶツールの宣伝は29件・訪問53人・利用0。X は11件・訪問12人・利用8。来てくれる場所と遊んでくれる場所が違う、という正直な記録」
- 10:30 に、この投稿は「材料にない数字（29件・53人・12人）が入ったため見送り」になった
- 同じ数字は、朝会の見立てにそのまま書いてあった

## 意外だった所・ぶつかった所
- 投稿の前に、実績に見える数字が材料にあるかを機械で照らす仕組み（作り話を外に出さないため）が、正しい数字を止めた
- 原因は、普通の投稿を書くときの材料に、朝会が見ている場所ごとの宣伝の成績が入っていなかったこと。AIは正しい数字を書いたのに、照らす側が知らなかった

## 人がしたこと・言ったこと
- 運営者が、ほかに直したほうがよい所を聞き、Claude Code がこれをいちばんに挙げると、運営者が「数字の確かめから」直すと決めた

## どうなったか
- PR #197 で、普通の投稿の材料に、宣伝の成績（場所×案件の型）と直近7日の日ごとの数字を足した。材料にない数字を止める決まりは変えていない（11/26 に本番に出た）
- 実際に、数字の入った普通の投稿が通るかは、次に朝会がそういう投稿を予定に入れたときに分かる

## まだ分からないこと
- 朝会のあとに数字が動いたとき（訪問が53人から54人に増えるなど）は、まだ止まることがある（PR #197 の ai-review の指摘。直していない）
