# AIの朝会が、数字を見て、宣伝を Threads から X の夜に寄せると自分で決めた

- 日付: 2026-11-26
- 関わるもの: 本番の「毎日の計画」（11/26 08:03 に作成。担当 Claude Opus 5.5）

## 起きたこと
- 朝会の担当のAIが、場所ごとの宣伝の成績（直近14日）を見た。Threads × 遊ぶツールは29件・訪問53人・利用0、X × 遊ぶツールは11件・訪問12人・利用8
- その日の方針を「新規を休み、利用率の高い X の夜に、遊ぶツール（#76・#74・#77）の宣伝を寄せる」にした。投稿の数は、X 宣伝3・Threads 宣伝2と普通2・Bluesky 普通1
- Bluesky は「宣伝59件で成果0」として、宣伝を止めて普通の投稿だけ残した
- 9:00 に、5人が画面にツールを入れたのに操作0だった #73 を「開いてすぐ指で描ける」画面に直して公開した（根拠は調べもの19）

## AIに渡していた指示・人が先に決めていたこと
- 朝会のAIへの指示（`src/lib/plan.ts`）に、人が先に書いていた: 「宣伝先の配分は、訪問の平均ではなく、直近14日の利用数（事前登録LPなら登録数）と利用率で決める」（11/23。提案箱 #92 から、PR #157）、「費用は、1訪問あたりではなく1成果あたりで比べる」「場所ごとの数は成績から決める」（11/25。運営者の判断。PR #175・改善の記録 `post-mix.json`）
- 11/27 に追記: 前の版のこの種は、上の指示を読まずに「人がしたこと: なし（朝会はAIだけで決めた）」と書いていた。そのため記事の下書きでも、使われた数で選んだのをAIの気づきとして書いてしまった

## 思ったのと違った所
- 訪問を集めているのは Threads なのに、AIは訪問ではなく「使われた数」を見て、訪問の少ない X に寄せた
- 宣伝の数を場所ごとにAIが自分で決め、理由と一緒に残している（「X 宣伝3（遊ぶツールで直近14日に利用8・1成果約41円と最も成果が高いので増やす）」）
- 朝会では GPT-6.2 Sol と Gemini 3.1 Pro の意見も聞き、取り入れたもの・取り入れなかったものを理由つきで書いた（例: Gemini の「#76 の Threads 集中」は、Threads × 遊ぶツールが利用0のため取り入れなかった）
- 試しを2件始め、結果ごとの次の手を先に決めた（例: #73 は「登録・利用が1以上 → X の夜に控えめな一言で宣伝」「0 → 描画枠の中に見本の丸を薄く出す」）

## 人がしたこと・言ったこと
- 11/26 の朝会の当日は、人は何もしていない（朝会はAIだけで開いた）
- ただし、使われた数で配分する物差しと、費用を1成果あたりで比べることは、人が先に指示に書いていた（上の「AIに渡していた指示」）
- 11/25: 運営者が、X がいちばん成果が良いのに投稿が少ない理由を聞き、投稿の数もAIに決めさせてよいと言った（改善の記録 `post-mix.json`）。11/23 に「利用数で配分する」を足したあとも、指示に「費用も考える（X はリンク付きの投稿が高い）」と1訪問あたりの費用だけ、「週3件まで」の上限が残っていて、X が少ないままだった

## どうなったか
- 8時の時点で訪問3。AIの予想は訪問18・登録/利用2（理由つき）
- X に宣伝を寄せた結果は、そのあとの X の投稿の訪問・利用の実績で振り返る
- #76・#73 の試しの判定（#76 は 11/29 08:03、#73 は 11/30 08:03 の予定）は、それぞれ別の試しの答え（#73 は、画面を直したあとの登録・利用）で、X への配分を変えた結果ではない
- #76 は、11/26 21:29 に「広がる」の3日の判定（遊んだ人1人）で集客お休みになり、試しは判定の前に止まった（提案箱 #105 で、コードの見直しが指摘した）

## まだ分からないこと
- 予定どおりに X の投稿が出たか（11/26 の8時の時点では、9件の予定のうち1件が済み。投稿の結果は、計画の画面の予定の欄で見られる）
- X に寄せて、全体の登録・利用が増えるか
- 件数が少ないので、Threads と X の差が偶然かどうか

## AIと仕事をして分かった、明日変えられること
- プロンプトに決まりを足すときは、同じことに触れている前の行（費用の見方・上限など）を先に探して、そろえる。足しただけでは、前の行に引っぱられて効かないことがある（11/23 に足して、11/25 にそろえるまで X は少ないままだった）。AIで開発しているエンジニア向け
- 「見られた数より使われた数で選ぶ」は、宣伝の常識なので、それだけでは記事の芯にならない
