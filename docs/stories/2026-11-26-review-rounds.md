# AIのレビューは、同じ PR に4回、毎回ちがう指摘を出した

- 日付: 2026-11-26
- 関わるもの: PR #208・#209・#211（ai-review。GPT のレビュー）

## 起きたこと
- #208（ページの直しの答え合わせ）・#209（判断の基準をねらいごとにする）・#211（教訓のたどり）で、push するたびに GPT のレビュー（ai-review）が回り、3つともそれぞれ4回レビューされた
- 1回目・2回目には、直す必要のある指摘があった（例: #208 で、公開する前の版にも答え合わせを始めていた・期限のあとの訪問も数えていた。#211 で、朝会で変えた予定ではなく、同じ案件の別の施策の結果を拾っていた）
- 回を重ねると、前の回に「直さない」と決めた点を言い換えた指摘や、同時に定例会議を開いたときの件数など、起きにくい場合の指摘が多くなった
- #211 の3回目・4回目では、決めて外した動き（朝会の試しには教訓を付けない）を、🔴（直すべき）として指摘した

## 意外だった所・ぶつかった所
- 指摘を直すと、直した所のまわりに新しい指摘が出た
- PR の説明文に「直さないと決めたこと」を理由と一緒に書くと、同じ指摘は出にくくなったが、言い換えて出ることもあった（ai-review は説明文を要件として読む）

## 人がしたこと・言ったこと
- 運営者が、本当の問題だけを直して、そのあとのレビューで細かい指摘だけなら、直さずにマージすると決めた（#208・#209・#210・#211 で、この進め方にした）

## どうなったか
- #208・#209 は 11/26、#211 は 11/27 にマージし、本番に出た
- 直さなかった指摘は、それぞれの PR の説明文に、理由と一緒に残した

## まだ分からないこと
- 直さなかった指摘が、本番で問題になるか
- どこで区切るかを、人が毎回決めずに済む決め方があるか
