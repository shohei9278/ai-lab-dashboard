# 提案箱のルーティンは、頼まれた提案を一度も見送っていなかった

- 日付: 2026-11-26
- 関わるもの: PR #205・#203、本番の「提案箱」

## 起きたこと
- 11/26 の本番の提案箱で、クラウドの Claude Code（提案箱のルーティン）が直してマージした提案は17件、「直さなくて良い」と判断して見送った提案は0件だった
- 11/26 15:15 に頼まれた #71（定例会議の点 5.8）では、提案の「中身がない区画を表示順から外す、または中身を作る」のうち、「中身を作る」を AI を呼び直す費用がかかるとして外し、残りだけで PR #203 を作った

## 意外だった所・ぶつかった所
- ルーティンが見送ってよいのは、「すでに入っている・いまのコードに合わない・大きすぎて1つの PR に収まらない・決め手が足りない」の4つだけで、「効き目が薄い」「今ある仕組みと重なる」では見送れなかった
- 手順の書き出しは「提案を1つ直して、PR を作ります」だった
- 7点以上の提案がなくなり、5〜7点の提案も自動で頼まれるようになっていた
- PR をマージするかを見る GPT と Gemini のレビューは、正しく書けているかを見るが、直す値打ちがあるかは見ない

## 人がしたこと・言ったこと
- 運営者が、提案箱の自動のルーティンに見送りが全然ないが、そんなものかと聞いた
- Claude Code が、見送る基準が技術的なものだけで、効き目が薄いものを見送る基準がないと伝えると、運営者が基準を足すと決めた

## どうなったか
- PR #205 で、見送る基準に「直しても効き目がはっきりしない」「今ある決まりや仕組みとほぼ重なる」「中心を削らないと1つの PR に収まらない」を足し、迷ったら見送るとした（11/26 に本番に出た）
- 運営者が書いた提案・運営者が押して頼んだ提案は、効き目と重なりだけでは見送らない

## まだ分からないこと
- ルーティンが実際に見送るようになるか。見送りすぎて、必要な直しまで止めないか
